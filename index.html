Robust computational imaging algorithms for inverse problems with coherent X-rays

Welcome

Welcome to the website of the ICASSP IPCX 2026 workshop Robust computational imaging algorithms for inverse problems with coherent X-rays. The workshop brings together researchers working on phase retrieval, holographic and ptychographic imaging, implicit neural representations, and machine learning for inverse problems at synchrotron and X-ray facilities.

The program features invited talks by leading experts as well as contributed presentations. See the Program page for the schedule and the Main speakers and abstracts page for talk details.
